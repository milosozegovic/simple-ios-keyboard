2. PURPOSE AND TARGET AUDIENCE
Simple Keyboard is a custom keyboard for people who find the default iPhone layout slow, especially people moving to iPhone from another phone. It adds a permanent row of numbers above the letters, places comma and period beside the spacebar, and provides two pages of symbols. Long-pressing S, C, D or Z offers š, ć, č, đ and ž, the letters used in Serbian, Croatian, Bosnian and Montenegrin Latin, and long-pressing the period offers ? ! ' and ". The value is faster everyday typing without switching keyboard pages.

3. SETUP AND MAIN FEATURES
No login, credentials or sample files are needed.
a) Open Settings → General → Keyboard → Keyboards → Add New Keyboard… and choose Simple Keyboard. (The app's "Open Settings" button opens Settings.)
b) Open the Simple Keyboard app, or any app with a text field, and tap the text field.
c) Touch and hold the globe key and choose Simple Keyboard.
d) Type using the numbers row, and the comma and period beside the spacebar.
e) Tap 123 for the first symbols page, then 1/2 for the second; tap ABC to return.
f) Touch and hold S, C, D, Z or the period key to see the extra characters.
g) Optional: Settings → General → Keyboard → Keyboards → Simple Keyboard → Allow Full Access. Full Access is requested only to enable haptic feedback, which iOS does not allow keyboards without it. The keyboard is fully functional with Full Access turned off.

4. EXTERNAL SERVICES
None. The app uses no servers, data providers, authentication services, payment processors, analytics or AI services. The keyboard is built with the KeyboardKit library, which runs entirely on the device. The keyboard contains no network code and collects no data.
